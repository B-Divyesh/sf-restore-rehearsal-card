Run the sample locally

$ rrc demo

The command creates a temporary workspace, runs the checks, cleans up Docker, and prints the signed card path.

What the sample includes

  • One PostgreSQL Compose service with a health check.
  • One SQL backup containing a non-sensitive probe row.
  • One exact row-count assertion and an Ed25519-signed card.

It uses Docker locally. It does not read your manifests or change browser storage.
